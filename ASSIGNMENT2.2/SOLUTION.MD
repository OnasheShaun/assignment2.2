## 1. Aim

To create a resume-style personal introduction webpage using HTML headings, paragraphs, text formatting elements, divisions, spans, and horizontal separators.

## 2. Requirements

- Visual Studio Code
- A web browser
- Basic knowledge of HTML
- An `index.html` file

## 3. Procedure

1. Open Visual Studio Code.
2. Create a folder named `Assignment-2.2`.
3. Create a file named `index.html`.
4. Write HTML code using the required elements.
5. Add sections for About Me, Education, Skills, and Hobbies.
6. Save the file using `Ctrl + S`.
7. Open the webpage in a browser and verify the output.

## 4. HTML Elements Used

| Element          | Purpose                                         |
| ---------------- | ----------------------------------------------- |
| `<h1>` to `<h6>` | Define headings at different levels.            |
| `<p>`            | Defines a paragraph.                            |
| `<br>`           | Inserts a line break.                           |
| `<hr>`           | Creates a thematic separator.                   |
| `<strong>`       | Indicates important text.                       |
| `<em>`           | Emphasizes text.                                |
| `<i>`            | Represents text in an alternate voice or style. |
| `<div>`          | Groups related block-level content.             |
| `<span>`         | Groups inline content for styling.              |

## 5. Result

Successfully created a personal introduction webpage with sections for personal information, education, technical skills, and hobbies using the required HTML elements.
